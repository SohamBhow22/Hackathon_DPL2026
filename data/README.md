# Data

The DPL 2026 preliminary-round analysis uses the organiser-provided
Premier League dataset.

## Expected location

Place the organiser-provided CSV at:

data/raw/Data_Premier_League_Prelims_Dataset.csv

The raw dataset is intentionally excluded from version control.

## Data source

The dataset was provided by the DPL 2026 organisers.

No web scraping is used in this project.

## Dataset structure

The dataset contains delivery-level cricket data, including:

- Match information
- Batting and bowling information
- Innings state
- Player identifiers
- Batting handedness
- Bowling style
- Bowling category
- Shot type
- Shot control
- Wagon-wheel information
- Bowling speed category
- Bowling release point
- Win probability
- Predicted innings score

See `docs/metric_definitions.md` for analytical definitions.
