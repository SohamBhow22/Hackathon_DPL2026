# Data

## Source

This project uses the DPL 2026 organiser-provided dataset.

The raw dataset is not committed to version control.

## Expected location

Place the dataset at:

`data/raw/Data_Premier_League_Prelims_Dataset.csv`

## Data handling

The `raw` directory contains the original organiser-provided data.

The `processed` directory contains datasets derived from the raw data
through reproducible transformations implemented in `src/`.

## External data

No web scraping is used in this project.

Any future external data source, if permitted and used, will be
documented explicitly in the project methodology.
