# DPL 2026 — KKR Analytics

Analytics project for the DPL 2026 hackathon.

## Objective

Perform a comprehensive analytical assessment of Kolkata Knight Riders
using the organiser-provided Premier League dataset, with the objective
of identifying performance drivers, tactical patterns, player value and
actionable strategic opportunities.

## Data

The project uses the organiser-provided DPL dataset.

The raw dataset is excluded from version control.

See `data/README.md` for data setup instructions.
